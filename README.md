# MYGAME — свой Вальхейм в живом мире

Игра на Unity 6.5 (URP): выживание, стройка, прокачка и путь героя — в тёплом
волшебном мире «доброго Kenshi», где NPC живут своей жизнью, а мир продолжается
без игрока. Слой нарратива — сатирический эпос вокруг **Камня Силы**.

Метод: **FPF** (First Principles Framework) + пайплайн Research → Design → Plan →
Implement + Clean Architecture. Правила — в [`CLAUDE.md`](./CLAUDE.md).
Управление работой — Jira (проект SCRUM «GAME-DEV»).
