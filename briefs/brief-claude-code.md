## Контекст
Игра на Unity 6.5 (URP): свой Вальхейм в тёплом живом мире «доброго Kenshi», срез «Первая ночь» (Альпы), нарратив вокруг «Камня Силы». Репозиторий: github.com/kisa134/gamegamegame. Документы — папка `docs/` (00–09). **Прочитай `CLAUDE.md` (закон проекта), `docs/03-архитектура-ядра.md`, `docs/05-план-первая-ночь.md`, `docs/09-оркестрация-флота.md`.** Задачи — Jira, проект SCRUM «GAME-DEV», эпик SCRUM-6.

## Железные правила (из CLAUDE.md)
Clean Architecture, зависимости внутрь: `Game.Domain` (без UnityEngine) → `Game.Application` (Use Cases, порты, Event Bus) → `Game.Unity` (адаптеры). Rich Entities (приватные поля, инварианты в методах). Игрок = ИИ через одни Use Cases. События публикуют Use Cases, не сущности. Гейты: ноль UnityEngine в Domain/Application; инварианты не обходятся; всё покрыто headless-тестами. Пайплайн Research→Design→Plan→Implement. В `main` не мёржишь — финальный мёрж за Principal (Юра).

## Твоя полоса (чтобы не конфликтовать с Cursor)
Cursor ведёт **чистое ядро** (`Game.Domain`, Story 1). Твоя полоса — **`Game.Application` (Use Cases + порты) и тяжёлые мультифайловые рефакторы**, позже — драйв Unity-редактора через Unity MCP. Работаешь в **отдельных файлах и своей ветке `feature/jira-SCRUM-…`**.
